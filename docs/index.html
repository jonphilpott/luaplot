luaplot

A Lua-scriptable toolkit for pen plotters running GRBL.

Overview

luaplot lets you write Lua scripts that drive a pen plotter directly over serial, render to SVG for previewing, or save G-code to a file for repeatable playback. Lua 5.4 is bundled — the only dependency is a C compiler.

The API is modelled on Processing: a push/pop transform stack, Y-down coordinates, and simple drawing primitives. luaplot takes care of Y-axis flipping, pen servo control, and GRBL flow control so your scripts stay readable.

Building

First-time setup — downloads Lua 5.4.7 source into lua-src/:

make fetch-lua

Then build the luaplot executable:

make

Run a script:

./luaplot examples/hello.lua

Pass extra arguments after the script name — they are available to the script as arg[1], arg[2], etc.

Output modes

The mode field in plotter.init() controls where output goes.

ModeDescription
serial Send G-code to the plotter in real time. Each command blocks until GRBL replies ok, preventing buffer overrun.
svg Write an SVG file. No hardware required — good for previewing and iterating on a design.
gcode Write a .nc G-code file. Send it to the plotter later with any G-code sender for repeatable results.
both Send to the serial port and write an SVG simultaneously.

Coordinate system

luaplot uses a Y-down, origin top-left coordinate system in scripts — the same as Processing and most drawing APIs. Positive X goes right, positive Y goes down.

GRBL homes to the bottom-left of the work area with Y increasing upward. luaplot flips Y automatically when emitting G-code: 

gcode_y = height - lua_y

SVG also uses Y-down, so no conversion is needed there. You never need to think about this unless you are reading the raw G-code output.

Transform stack

luaplot maintains a stack of 2D affine matrices. Every drawing call transforms its coordinates through the matrix at the top of the stack before output.

push() saves the current transform; pop() restores it. Calls to translate(), rotate(), and scale() modify the current matrix in place. Transforms compose in the order you write them — the same as Processing. 

-- draw a rectangle rotated 30° around the point (100, 100)
plotter.push()
  plotter.translate(100, 100)   -- move origin to pivot point
  plotter.rotate(30)            -- rotate 30° clockwise
  plotter.translate(-25, -25)  -- shift so rect is centred on origin
  plotter.rect(0, 0, 50, 50)
plotter.pop()
-- back to whatever transform was active before push()

The matrix is a standard 2D affine transform stored as six values {a, b, c, d, tx, ty}: 

x' = a·x + b·y + tx
y' = c·x + d·y + ty

API reference

All functions are on the table returned by require 'plotter'.

plotter.init( config )

Initialise the plotter. Must be called before any drawing. Resets the transform stack and all internal state.

KeyTypeDefaultDescription
mode string "svg" Output mode: "serial", "svg", "gcode", or "both"
width number 200 Work area width in mm
height number 200 Work area height in mm
port string "/dev/ttyUSB0" Serial port path (serial/both only)
baud number 115200 Baud rate (serial/both only)
feed number 1000 Drawing feed rate in mm/min (serial/both only)
pen_up number 90 Spindle S value for pen-up servo position
pen_down number 30 Spindle S value for pen-down servo position
svg_file string "output.svg" SVG output path (svg/both only)
gcode_file string "output.nc" G-code output path (gcode mode only) 
local plotter = require 'plotter'

plotter.init {
    mode     = "svg",
    width    = 200,
    height   = 200,
    svg_file = "my_drawing.svg",
}

plotter.push()

Save the current transform matrix by pushing a copy onto the stack.

plotter.pop()

Restore the transform saved by the last push().

plotter.translate( dx, dy )

Move the origin by dx, dy.

plotter.rotate( angle )

Rotate the coordinate system by angle degrees clockwise (in Y-down space). The rotation is around the current origin — use translate() first to rotate around an arbitrary point.

plotter.scale( sx [, sy] )

Scale the coordinate system. If sy is omitted, uniform scaling is applied. Passing different values for sx and sy will produce non-uniform scaling — a circle primitive becomes an ellipse, for example.

plotter.line( x1, y1, x2, y2 )

Draw a straight line from (x1, y1) to (x2, y2). The current transform is applied to both endpoints.

plotter.rect( x, y, w, h )

Draw a rectangle. (x, y) is the top-left corner; w and h are width and height. Drawn as four separate lines, so the transform applies naturally — rotating the coordinate system rotates the whole rectangle.

plotter.circle( cx, cy, r [, steps] )

Draw a circle centred at (cx, cy) with radius r, approximated as a polygon with steps sides (default 36). Increase steps for smoother circles at large sizes.

Applying scale() before drawing a circle produces an ellipse.

plotter.text( x, y, str, height )

Draw str using the Hershey Roman Simplex single-stroke font. (x, y) is the left end of the baseline; height is the cap height in drawing units. Returns the total advance width so calls can be chained.

Single-stroke fonts are ideal for plotters — each letter is drawn with the minimum number of pen lifts.

plotter.text_width( str, height )

Returns the advance width of str at the given cap height in drawing units, without drawing anything. Use this to calculate positions before calling text() — for example to centre or right-align a string.

plotter.polyline( points [, close] )

The core primitive. Draw a connected path through a list of {x, y} tables. If close is true, a final segment is drawn back to the first point. The pen goes down once at the start and up once at the end — far more efficient than calling line() repeatedly for connected paths. 

plotter.polyline({ {10,10}, {50,30}, {90,10} }, false)  -- open path
plotter.polyline({ {10,10}, {50,80}, {90,10} }, true)   -- closed triangle

plotter.polygon( points )

Draw a closed shape through an arbitrary list of {x, y} points. Equivalent to polyline(points, true). 

-- equilateral triangle
plotter.polygon({ {100,60}, {135,120}, {65,120} })

plotter.arc( cx, cy, r, start_angle, end_angle [, steps] )

Draw a portion of a circle. Angles are in degrees, measured clockwise from the positive X axis (consistent with Y-down screen space). steps defaults to a value proportional to the angular span. 

-- semicircle opening downward
plotter.arc(100, 100, 40, 0, 180)

-- three-quarter arc
plotter.arc(100, 100, 40, 0, 270)

plotter.ellipse( cx, cy, rx, ry [, steps] )

Draw an ellipse centred at (cx, cy) with horizontal radius rx and vertical radius ry. Unlike scale() + circle(), this does not affect the current transform. 

plotter.ellipse(100, 100, 60, 30)  -- wide flat ellipse

plotter.bezier( x1, y1, cx1, cy1, cx2, cy2, x2, y2 [, steps] )

Draw a cubic Bézier curve from (x1, y1) to (x2, y2). (cx1, cy1) and (cx2, cy2) are the control points that pull the curve. steps defaults to 20.

The cubic Bézier formula: P(t) = (1-t)³P₀ + 3(1-t)²t·P₁ + 3(1-t)t²·P₂ + t³P₃ where t runs from 0 to 1. 

-- gentle S-curve
plotter.bezier(40, 150,   40, 60,   160, 140,   160, 50)
local advance = plotter.text(10, 50, "Hello", 20)
plotter.text(10 + advance, 50, " world", 20)

plotter.penup()

Lift the pen. Sends M3 S<pen_up> followed by a short dwell so the servo reaches position before the next move. Has no effect if the pen is already up.

plotter.pendown()

Lower the pen onto the paper. Sends M3 S<pen_down> and a dwell. Has no effect if the pen is already down.

Note: The drawing primitives (line, rect, etc.) manage the pen automatically — you only need penup() and pendown() if you are building custom motion sequences directly.

plotter.done()

Finalise output. Always call this at the end of your script.

  • serial / both: lifts the pen, returns to home (G0 X0 Y0), turns off the spindle (M5), closes the serial port.
  • svg / both: writes the SVG file.
  • gcode: writes all accumulated G-code to the output file.

Examples

Hello world

The simplest possible script — a border and a line of text. Save as examples/hello.lua and run: 

./luaplot examples/hello.lua
local plotter = require 'plotter'

plotter.init {
    mode     = "svg",
    width    = 200,
    height   = 200,
    svg_file = "hello.svg",
}

-- 5 mm inset border
plotter.rect(5, 5, 190, 190)

-- text with a cap height of 20 mm
plotter.text(20, 100, "Hello, plotter!", 20)

plotter.done()

To send to the plotter instead of writing SVG, change mode to "serial" and add the port and baud settings: 

plotter.init {
    mode     = "serial",
    width    = 200,
    height   = 200,
    port     = "/dev/tty.usbmodem1101",
    baud     = 115200,
    feed     = 1500,
    pen_up   = 90,
    pen_down = 35,
}

Using the transform stack

This example draws a 4×4 grid of squares, the whole grid rotated 15° around its own centre. The key pattern is push / set up transforms / draw / pop. 

local plotter = require 'plotter'

plotter.init { mode = "svg", width = 200, height = 200 }

-- The grid is 4 columns × 4 rows of 11 mm cells (8 mm square + 3 mm gap).
-- Total grid size: 44 mm × 44 mm.  We want it centred at (100, 100).
plotter.push()
    plotter.translate(100, 100)  -- move origin to grid centre
    plotter.rotate(15)            -- rotate 15° clockwise
    plotter.translate(-22, -22)  -- shift so grid is centred on origin

    for row = 0, 3 do
        for col = 0, 3 do
            plotter.rect(col * 11, row * 11, 8, 8)
        end
    end
plotter.pop()

plotter.done()

You can nest push()/pop() pairs to any depth. Each level inherits the parent transform and adds its own on top. 

-- Nested transforms: outer rotation + inner per-cell variation
plotter.push()
    plotter.translate(100, 100)
    plotter.rotate(15)

    for i = 0, 7 do
        plotter.push()                   -- save outer transform
            plotter.translate(i * 10, 0)
            plotter.rotate(i * 5)         -- each cell rotated a bit more
            plotter.rect(-4, -4, 8, 8)
        plotter.pop()                    -- restore outer transform
    end
plotter.pop()

Generative pattern

Concentric rings of circles with increasing angular offset — the kind of thing that takes five minutes to write but looks like it took five hours to plan. 

local plotter = require 'plotter'

plotter.init {
    mode     = "svg",
    width    = 200,
    height   = 200,
    svg_file = "rings.svg",
}

local cx, cy  = 100, 100   -- centre of the composition
local rings   = 6          -- number of concentric rings
local per_ring = 8         -- circles per ring
local r_small = 6          -- radius of each small circle (mm)

for ring = 1, rings do
    local orbit  = ring * 13             -- distance from centre
    local offset = ring * (360 / per_ring / rings)  -- angular stagger

    for i = 0, per_ring - 1 do
        local a  = math.rad(i * (360 / per_ring) + offset)
        local px = cx + orbit * math.cos(a)
        local py = cy + orbit * math.sin(a)
        plotter.circle(px, py, r_small, 24)
    end
end

plotter.done()

To save the G-code for repeatable plotter output, change mode to "gcode": 

plotter.init {
    mode       = "gcode",
    width      = 200,
    height     = 200,
    gcode_file = "rings.nc",
    feed       = 1500,
    pen_up     = 90,
    pen_down   = 35,
}

The resulting rings.nc can be sent to the plotter with any GRBL-compatible G-code sender and will produce identical output every time.

Text layout

plotter.text() returns the advance width of the string, which makes it straightforward to chain calls or compute a centred position. 

local plotter = require 'plotter'

plotter.init { mode = "svg", width = 200, height = 150 }

-- Chained text — second word starts where the first ends
local x = 10
x = x + plotter.text(x, 40, "Hello", 18)
x = x + plotter.text(x, 40, ", ", 18)
x = x + plotter.text(x, 40, "world.", 18)

-- Rotated text using the transform stack
plotter.push()
    plotter.translate(20, 130)
    plotter.rotate(-10)
    plotter.text(0, 0, "Tilted label", 12)
plotter.pop()

plotter.done()

To centre a string horizontally, measure it first with plotter.text_width() then draw at the calculated position: 

local label   = "CENTRED"
local cap_h   = 20
local start_x = 100 - plotter.text_width(label, cap_h) / 2
plotter.text(start_x, 80, label, cap_h)
plotter.done()
